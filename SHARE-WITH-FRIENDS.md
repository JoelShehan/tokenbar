# TokenBar 0.1.1 — Windows x64

Install TokenBar, open the widget, click **Connect Codex**, and sign in with
ChatGPT in your browser. Return to TokenBar to see your Codex usage. No terminal,
Node.js, or separate Codex installation is needed.

The OpenAI API section is optional. Enable it in Settings only if you want to
connect an organization Admin API key for API usage and costs.

Use Settings → Codex connection → Disconnect Codex to remove the widget
connection. It is separate from any other Codex app or CLI on your computer.
Click the tray icon to show/hide TokenBar; choose Quit from its menu to exit.

This installer is unsigned, so Windows may display an unknown-publisher or
SmartScreen warning. Automated checks pass; real browser sign-in and a second
clean laptop remain unverified. Share this as a test build.

Windows x64 only. The installer can download WebView2 if the runtime is missing;
an internet connection is needed for that and for sign-in/usage updates.
